Price / Weight adds a value-to-weight ratio to item tooltips and a matching inventory sort option in The Witcher 3.

Quickly compare loot by value per unit of carry weight, sort items with the highest ratio first, and spend less time doing inventory math.

Features:

• Price / Weight displayed in item tooltips
• New Price / Weight sorting option
• Highest ratios sorted first
• Fully localized for every language supported by The Witcher 3

Known limitation in version 1.0: the vanilla inventory grid may affect the visible sorting order in some tabs. The displayed Price / Weight values remain correct.

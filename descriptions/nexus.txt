TITLE
-----
Price-Weight - Inventory Tooltip and Sorting


SHORT DESCRIPTION
-----------------
Adds a Price / Weight value to item tooltips and a matching inventory sort option, helping you find the most valuable loot per unit of carry weight.


DESCRIPTION (paste everything between the lines)
------------------------------------------------------------------------
[size=4][b]DESCRIPTION[/b][/size]
[color=#D4D4D8][b]Price / Weight[/b] adds a value-to-weight ratio to item tooltips and a matching option to the inventory sorting menu.[/color]

[color=#D4D4D8]The higher the number, the more crowns the item is worth per unit of carry weight - making it easier to decide what to keep, sell, or drop without doing the math yourself.[/color]

[youtube]pxSG0zXrIO8[/youtube]

[size=4][b]FEATURES[/b][/size]
[list]
[*]Displays [b]Price / Weight[/b] in item tooltips[/*]
[*]Adds [b]Price / Weight[/b] to the inventory sorting menu[/*]
[*]Sorts items with the highest ratio first[/*]
[*]Lists weightless items after all weighted items[/*]
[*]Localized for every language supported by The Witcher 3[/*]
[/list]

[size=4][b]CALCULATION[/b][/size]
[color=#D4D4D8]Price / Weight = displayed price ÷ displayed weight
Example: 1772 ÷ 2.04 = 868.63[/color]

[size=4][b]COMPATIBILITY[/b][/size]
[color=#D4D4D8]This mod changes the inventory tooltip and inventory sorting interface files. If another mod changes the same inventory interface, only one mod's version can be active, and a compatibility patch may be required.[/color]

[size=4][b]INSTALLATION[/b][/size]
[list=1]
[*]Extract the downloaded archive.[/*]
[*]Copy the [b]modPriceWeight[/b] folder into your [b]The Witcher 3\Mods[/b] directory.[/*]
[/list]

[size=4][b]UNINSTALLATION[/b][/size]
Remove the [b]modPriceWeight[/b] folder from your [b]Mods[/b] directory.

------------------------------------------------------------------------
<p><strong>Price / Weight</strong> adds a value-to-weight ratio to item tooltips and a matching option to the inventory sorting menu.</p>
<p>The higher the number, the more crowns the item is worth per unit of carry weight. This makes it easier to decide what to keep, sell, or drop without doing the math yourself.</p>
<p><a href="https://youtu.be/NEW_VIDEO_ID">Watch the demo on YouTube</a></p>

<h2>Features</h2>
<ul>
<li>Displays <strong>Price / Weight</strong> in item tooltips.</li>
<li>Adds <strong>Price / Weight</strong> to the inventory sorting menu.</li>
<li>Sorts items with the highest ratio first.</li>
<li>Lists weightless items after all weighted items.</li>
<li>Localized for every language supported by The Witcher 3.</li>
</ul>

<h2>Calculation</h2>
<p>Price / Weight = displayed price ÷ displayed weight</p>
<p>Example: 1772 ÷ 2.04 = 868.63</p>

<h2>Compatibility</h2>
<p>This mod changes the inventory tooltip and inventory sorting interface files. If another mod changes the same inventory interface, only one mod's version can be active, and a compatibility patch may be required.</p>

<h2>Installation</h2>

<h2>Uninstallation</h2>
